# FlowPilot

FlowPilot is a responsive B2B SaaS marketing website for a fictional AI workflow automation platform. It was built as a Web Developer hiring assignment with reusable React components, accessible interactions, route-level SEO, and structured data.

## Features

- Home, Product, Pricing, and Contact routes
- Responsive navigation, pricing cards, FAQs, testimonials, and contact form
- Route-level lazy loading and scroll restoration
- Accessible semantic HTML, keyboard support, visible focus states, and skip navigation
- Per-route metadata, canonical URLs, social tags, and JSON-LD

## Tech Stack

- React 19 and Vite 8
- React Router
- Tailwind CSS v4
- React Helmet Async
- Lucide React

## Folder Structure

```text
src/
├── components/   # Shared UI and SEO components
├── data/         # Site content and structured data
├── layouts/      # Shared application layout
├── pages/        # Lazy-loaded route pages
├── styles/       # Global and Tailwind styles
├── App.jsx       # Router configuration
└── main.jsx      # Application entry point
```
