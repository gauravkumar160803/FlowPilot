# Structured Data

FlowPilot provides JSON-LD through React Helmet Async. The home and contact experiences use `Organization` and `ContactPoint` schemas to identify the business and its contact channels. The product page uses `SoftwareApplication` to describe the web application. The pricing page uses `Product` and `Offer` data for standard plans plus `FAQPage` for its pricing questions. These schemas give search engines machine-readable context about the company, software, pricing, and FAQ content.
