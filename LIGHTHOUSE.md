# Lighthouse Optimizations

FlowPilot uses route-level lazy loading and Vite code splitting to reduce initial JavaScript. It avoids large raster images, external font requests, and third-party scripts, relying on compact SVG/CSS visuals instead. Unused starter assets were removed, and nonessential animation uses reduced-motion-safe CSS. Semantic HTML, accessible controls, visible focus states, labels, skip navigation, per-route metadata, canonical URLs, and JSON-LD support strong Accessibility, SEO, and Best Practices audits.
